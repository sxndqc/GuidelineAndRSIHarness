# 跨领域规范适应协议：方法学审查

日期：2026-10-06。审查依据：本仓库 `research-proposal.zh.md` 当前版本，以及新增 Manifesto 与 Fashionpedia 的研究要求。本文提出可执行协议，不声称已核验新增数据的全部版本、许可、规范或运行过模型。任务适配器必须以实际下载资源为准；这里的候选现象不是已确认的规范缺口。

## 结论与可主张范围

可以在语言学标注、政治文本分类和视觉属性标注之间共享**证据曝光、持久状态更新和冻结评测协议**，不应强行统一任务分数或把一次标签预测当作规范学习。新增任务改善领域覆盖，但 Fashionpedia 同时改变模态，因而领域差异与视觉能力无法从三个领域的平均分中分离。

建议主张：给定预训练系统与可检索的任务材料，不同持久状态更新方式对新增标注证据的利用效率如何变化。要把收益进一步解释为规范适应，至少需要冻结资产对未见实例的迁移，并在一个专家审计的规则边界或政策对照上获得证据。普通 accuracy/F1 上升仅支持任务适配。

## 1. 三种证据强度必须分开

1. **任务表现：** 原始规范下、独立实例上的预测质量与成本。这是全部任务都能提供的最低共同结果。
2. **边界迁移：** 专家先定义容易混淆的规范决策，在学习与评测材料之间控制表面表达、来源或视觉近重复；检验原例记忆之外的迁移。自动按错误聚类得到的现象只能标为探索性。
3. **政策敏感性：** 同一输入在两个明确、自洽的政策下应有不同答案；分别给对应材料，考察能否改变受影响决策并保持无关决策。可用经过核验的真实政策修订，也可用明确标为人为的受控新约定。简单重命名标签不足以证明规则学习。

规范资产写得像规则、能够引用章节、Agent 自称理解，均不能代替后两类行为证据。公开数据可能已用于预训练，“少样本”始终指新增监督量。

## 2. 共同实验协议

每个任务使用独立 workspace、例库与适应资产，不跨任务传递学习结果。基础模型权重固定。所有组共享初始 guideline、ontology、原生示例、输出 schema、非 gold 结构验证器和授权输入。

- **F：冻结工具 Agent。** 可以检索原例、分步推理和执行固定工具，不可更新持久规范或程序。
- **N：F + 持久笔记。** 允许写规范补丁、例外与索引；原例访问权保持一致。
- **NC：N + 自写程序。** 允许修改标注流程或自检程序。它与 N 的比较估计“笔记基础上增加代码权限”的增量，不是纯代码与纯笔记比较。

主实验由控制器生成嵌套随机示例顺序，F/N/NC 逐轮重放相同输入与 gold。先隔离证据利用能力；主动选择留到第二阶段，届时显式限制候选池可见范围、选择成本与标签购买预算。

Agent 只能向可信工具购买当前适应池的 gold。预算不足时工具拒绝且不返回任何标签相关信息。主实验的错误解释、gold diff 与自测评分只能来自已经购买的实例；禁止免费开发集 aggregate score。研究者开发集和最终测试分别隔离。

每个预算点冻结资产并计算 hash。每个测试实例从同一冻结快照启动，允许实例内临时文件和计算，结束后丢弃全部变化。控制器、评分器、gold、预算账本不挂载给 Agent。测试原始输入只提供当前实例的授权投影。关闭外网及未经预算登记的其他模型服务。

至少记录：任务/政策/材料版本、split 与来源 ID、购买事件、状态差异与来源例子 ID、模型版本、调用和计算成本、非法输出、超时、重试及最终评分。失败运行保留在结果中，不能只汇总成功样本。

## 3. 每个领域必须保持的差异

| 任务 | 首轮授权输入和预测对象 | 主要指标 | 关键隔离与解释限制 |
|---|---|---|---|
| SNACS（语言学代表） | 给定句子与目标表达，预测 role/function | 联合准确率，分别的 role/function 分数 | 给定表达边界属于任务输入；不能称端到端识别。按原文档隔离，剥离其他 gold 标注层 |
| Manifesto | 给定已分段 quasi-sentence，按锁定 codebook 预测所选编码层级 | accuracy、macro-F1、各类支持量与混淆 | 固定 codebook 与编码版本；相邻片段按 manifesto/document 成组，不能随机切片泄漏。分段预测另立轨道 |
| Fashionpedia | 给定图像和指定实例区域，预测已审计范围内的属性集合；类别是否给定必须预注册 | 多标签 micro/macro-F1、集合 exact match，空集合与非法标签单列 | 给定 box/mask 是结构输入；若给定 gold 类别则是条件属性任务。不是检测/分割 benchmark 的端到端结果 |

UMR、UD、GUM 继续使用原方案各自的结构指标，不换成一个通用“标签正确率”。Fashionpedia 的 conditioned attribute 指标是研究用派生评测，不冒称官方完整任务指标；正式完整任务再使用匹配版本的官方 evaluator。

**Manifesto：** 先核验实际 codebook 是否包含决策优先级、上下文使用、特殊/缺失编码及版本映射。不能把聚合党派统计值当成片段 gold。限定一个可获得充分独立文档的语言，之后再扩展跨语言；机器翻译后的样本另标派生条件。上下文窗口及党派/国家/年份元数据可见性必须所有组一致，预先指定。若研究跨党派或跨时间迁移，按对应组划分；不把同文档随机切分称为跨来源泛化。合理备选标签与政治解释分歧需保留，不能把所有冲突自动叫模型错误。

**Fashionpedia：** ontology/属性词表本身未必等于 annotation guideline。必须审计属性定义、适用类别、排他关系、标注完整性、遮挡/不可见处理和实例归属规则。若只有名称和数据，没有可验证决策规范，则该任务只能先支持 ontology-conditioned attribute prediction。尤其要核验“未列出属性”能否作为负例；未知/未标注不可擅自当负标签。若注释约定无法确认，只能报告与数据标签的匹配度，并明确其不是视觉真值的完备评价。

视觉首轮统一给全图与固定区域提示，或统一给确定性 crop；分辨率、resize、压缩与多图顺序固定。裁剪不得由 gold 属性决定。所有实例来自同一图像的样本必须进入同一 split；近重复产品图/拍摄系列在可识别时成组。禁止通过文件名、annotation JSON、EXIF 或 captions 泄漏类别/属性。

## 4. 可比较的预算是向量，不是一个“例子数”

主横轴仍为每任务新增唯一带标签单位数，但必须预先选择购买单位：SNACS 可为目标表达，Manifesto 为 quasi-sentence，Fashionpedia 为指定服装实例。一次购买只返回这个单位的 gold，不能顺便暴露同句/同图的其他答案。若工具只能返回整句/整图标注，则整句/整图为购买单位并据实记账。

同时记录：源文档/图像数、文本 token、决策数、正标签数、有效属性标签空间、图像尺寸/patch 或服务商 image token、图像读取次数、工具调用、适应与预测费用、人工标注时间（仅实测时报告）。属性集合的负标签是否随 gold 一并提供由数据约定决定，不能为了显得省样本只数正属性。

同一图片的多个 crop 是重复视觉处理，不是多个独立新图像；若揭示不同实例 gold，则产生多个购买单位。已购买例子可重读，唯一监督不重复计，但调用与图像处理费用累计。政治文档与图像单位的数字不可直接合并成一个“总样本复杂度”。

学习曲线和最小确认达标预算 B* 分任务报告，阈值提前确定；预算上限内未确认达标视为删失。跨任务可以汇报预注册配对效应的方向和区间，不直接平均 LAS、macro-F1 与图像 AP，也不把三领域当成足以估计所有领域总体的随机样本。

## 5. 模型与视觉瓶颈对照

为了在三类任务上比较能力档位，核心选择两个均支持原生视觉与工具调用的模型，并在文本任务也使用同一对版本。否则“强模型在视觉更好”可能只是另一模型没有视觉入口。能力档位事先指定，不按本研究得分事后划分。

分别报告同监督、相同调用/计算上限、同费用的结果；图像 token 不等价于文本 token，跨服务商 token 也不是完全可比的算力。固定费用结果若只做诊断必须明确，不能把它和主矩阵混合。

每个任务保留 guideline-only 和材料容量允许的 full-context 示例基线。Fashionpedia 的 full-context 必须真正包含相同授权图像，不能仅给文件路径。若视觉材料容量不允许，报告适用范围，不故意截断弱化基线。

至少为视觉错误增加一个小规模专家诊断：模型看不见相关特征、看见但不懂属性定义、定义已知但实例归属错误、合法格式失败。人工提供视觉描述会带来新监督，只可作为独立 oracle 诊断，不能当成原生视觉组的免费预处理。固定视觉编码器或人工 caption 的文本模型不能用于直接推断弱视觉模型的规范学习能力。

## 6. 可运行最小 pilot 及验收

**步骤一：真实数据 smoke test。** 每任务准备至少 2 个互不泄漏的适应购买单位与 2 个独立开发评测单位，仅用于排错。执行真实加载、购买、一次更新、冻结、真实模型预测及 evaluator。合成 fixture、echo gold、mock provider 都只证明 plumbing，不能记为模型实验。某个任务材料受阻时继续运行其他任务，受阻项明确记录具体缺失资源。

**步骤二：跨领域工程 pilot。** 使用 SNACS、Manifesto、Fashionpedia 三类代表任务；2 个预先指定模型 × F/N/NC 三组 × 预算 0/4/16 × 2 条共享示例轨迹，最多 108 个冻结评测单元。预算 0 的相同初态可共享。每任务约 30–50 个独立开发评测单位用于成本/格式/流程检查；尽可能来自多个源文档/图像。这个规模不是显著性保证，不承担“多少例子足够”的最终结论。若资源不足，先以单模型完成三领域工具流程，再增加第二模型；不得声称已比较强弱模型。

验收采用以下硬条件，**不以适配组必须胜出为门槛**：

1. 实际数据、图片、codebook/ontology/guide 的版本和获取状态可追溯，许可与使用范围记录；未获得规范时相应任务降为标签预测研究。
2. split 按源文档/图像隔离，适配后的 Agent 输入不含 gold 或派生泄漏字段；控制器测试证明未购买 gold 和最终测试 gold 不可访问。
3. 购买工具支持去重、超预算拒绝与账本核对；一次购买的监督单位符合第 4 节，重读不会免费暴露额外标签。
4. scorer 的 gold 自评分达到预期，错误/空/非法输出被确定处理；多标签缺失语义已审计，不能将“未知”静默变负例。
5. F 无持久更新；N/NC 的更新有真实差异与轨迹，冻结后测试实例互不污染。没有产生差异亦如实记录，不能用虚假“演化轮次”代替。
6. 真实模型响应、工具读取（视觉组有实际图像输入）、资产 hash、预算与费用可关联；凭空生成模型结果或从 gold 构造 prediction 会使实验不合格。
7. 超时、格式失败、重试和总成本可汇总并估算正式实验规模。模型失败率高应触发诊断，但仍是观察结果；不因弱模型失败而选择性删任务/运行。

正式研究还需至少一组专家审计的边界迁移/政策敏感性评测，否则论文结论只能是跨域少样本预测。专家审计和研究者 pilot 可以影响正式方法选择，最终测试则在方法锁定前保持不可见。

## 7. 对现有方案的必要更新

- 第 1/11 节的结论范围从“所测语言学标注”改为“所测语言学、政治文本和条件视觉属性任务”，同时写明视觉模态的混杂因素，不能仅因增加两个数据集就宣称通用标注能力。
- 将 Manifesto 的 codebook 适配与 Fashionpedia 的规范充分性审计设为数据门槛，而不是默认它们具有与 UMR 一样的规范缺口。
- 原 pilot 保留可复用基础设施；新增跨域 pilot 使用上述共享协议，不同时展开全部 UMR/UD/GUM × 模型 × 主动选择 × 模态条件。
- 核心资产效应、主动选例效应、视觉感知效应分别报告。测试输出质量不能单独确证“规范学习”；自写 harness 的存在不能单独确证“自演化”。
