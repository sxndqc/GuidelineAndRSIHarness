# Operational continuation amendment, 2026-10-06

The first four test jobs encountered two distinct request failures: one provider policy refusal (ledger 552), and one `Selected model is at capacity` response (ledger 629). Neither is evidence that login failed or API credit is required. The initial adapter globally stopped on any nonzero CLI exit, which incorrectly cancelled unrelated queued instances after a single refusal.

A refusal remains a terminal, failed prediction. Its exact prompt hash is registered and the refused request is never resubmitted. Interrupted episodes reconstruct the exact serialized conversation from their saved successful action/tool traces; the next step is resumed, preserving the original total action cap. Already completed episodes, including completed failures or tool exhaustion, are reused without rerunning. An automated test checks exact message equality across interruption. Native-tool violations and unknown protocol events still halt globally.

A capacity error can receive a delayed continuation on the same model; no different model substitutes for it. Luna workers are reduced from four to two as an operational scheduling change. This changes throughput, not evidence, seeds, sample selection, prompts, model identities, semantic scoring, or update acceptance. A recurring capacity failure remains an explicit external blocker rather than triggering indefinite retries.

The initial 6,000-call ceiling was underestimated for long-manual tool search across 1,792 prediction episodes plus adaptation. The extended ceiling is 18,000 official subscription calls; it is a hard upper bound, not a spending estimate or promise of available quota. The extension is based on observed call counts and latency, not comparative annotation accuracy. Original run configs and hashes remain; resume configs/hashes are stored separately. No API-dollar price is imputed. Provider quota exhaustion, if encountered, still stops work.

This is an operational amendment after some baseline test inference, not an untouched preregistration. The manuscript must disclose it. The original experimental grid and outcomes remain fixed; interrupted traces are archived locally and not replaced by successful-only results.

After review, new actor calls use at most three attempts for the **same exact capacity-rejected request**, with 30- and 60-second delays. This applies only to the explicit `Selected model is at capacity` response. All attempts remain in the call ledger; a refusal, unknown protocol, isolation violation, quota/authentication failure, or other error is not retried by this rule. Repeated capacity failure ends the run. Existing legacy interruptions require a separate raw-event audit before being marked resumable; timeout is not automatically classified as capacity.

Interruption archives are content-addressed. Continuation validates original material/data-manifest, evaluation IDs and batch snapshots; full projection content hashes were first captured at continuation for legacy runs, a provenance gap explicitly recorded. New runs capture them initially. Assets replay the canonical successful write path. Terminal refusal cache keys include the model, and inherited cached skips are distinguished from new provider refusals.
