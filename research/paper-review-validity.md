日期：2026-10-06。范围：修订代码、10 项测试、60 份真实非 LLM 预测、`results/control-analysis.json`、`paper/main.tex` 与表格。未编辑实验框架或稿件。

## 结论

**未发现阻止目前“研究协议 + 初步非 LLM controls”稿件报告这些数值的新重大错误。** 上轮指出的问题已修复。这个结论不等于完整 Agent 研究已完成或已经达到 ACL 实证要求；论文现有措辞已明确区分。

## 已核实修复

- `episode` 检查 JSON 对象、工具 arguments 和 evaluation prediction 结构，非法 finish 不再通过 list/null 触发控制器 `.get()` 崩溃。
- 输出合法率使用固定 SNACS ontology；不再把任意两字符串视为合法标签。
- 截断响应先保留 usage、响应 ID 与其他元数据，再返回 `truncated`；不丢弃已知费用依据。
- baseline predictor 只遍历公开输入 targets，不要求测试 gold；调用方显式移除 gold。
- baseline 输出目录非空即拒绝，避免无提示覆盖已有结果。
- 重新运行全部 10 项测试，均通过。

## 实证结果核对

独立读取 60 份 v2 prediction 文件，逐份重新计算 hash 和全部 `score_snacs` 指标：均与 v2 报告一致，且 60 个 hash 均与原始报告一致。重新汇总五条轨迹的均值和样本标准差，全部匹配 `paper/control-table.tex`。

## 仍然阻止“完整研究已完成”这一主张的事项

这些是已有、且稿件已披露的实证缺口，不是新增编码缺陷：

1. 没有真实 Agent 推理、持久资产适配或强弱模型结果，不能从 non-LLM controls 推断 self-evolution 有效或所需样例量。
2. Manifesto/Fashionpedia 尚无实际跨域预测；专家未确认自然规范缺口。候选资源审计不等于跨域验证。
3. 当前 supplied-target scorer 尚未完成与上游评测器的逐项交叉核对。可以按正文现有披露报告透明定义的派生指标，不应称为已复现官方完整任务分数。

本轮不要求扩大实验范围，也不要求为已正确限定的初步报告补造额外结论。
