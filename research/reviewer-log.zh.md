# AI 审稿记录

日期：2026-10-06。以下是三个独立子 agent 对研究方案的审查摘要，由主 agent 整理；不是外部人类评审，不代表 ACL 接收判断。没有实验稿件或结果可供审查，因此审的是研究计划。

## R1：贡献与最近邻

首轮：拒绝“机器学习不能读规范”与未定义的 self-evolution；要求冻结强 RAG、规范缺口类型与未见构式泛化。

第二轮：GoLLIE、GuideBench、CER、Gödel Agent 与工具增强标注已覆盖主要部件。建议经验/评测论文定位，不主张新 agent 架构。

第三轮（发现 ACL 2026 最近邻后）：Refining and Reusing Annotation Guidelines for LLM Annotation 已涉及专门标注约定、迭代精炼、少量监督和模型比较，原提案重复工作风险高。必须读全文并复现/重实现 moderation；其生物医学 NER 做校准，不加入所有预算配置。创新应是不同持久状态在同监督预算下的迁移与失效机制，而不能只是换成 UMR。

已采纳：收紧研究问题、撤去首次主张、将规范精炼改为强基线、加入最近邻复现与证据限定。未完成：最近邻全文和代码审读，不能确认最终新颖性。

## R2：实验有效性

首轮：工具检索、主动选例、记忆与代码、更多推理预算混淆；开发反馈也算监督；最终测试不可提供演化反馈。

第二轮：全矩阵费用过大，建议先做 UD/SNACS×2模型×3条件×3预算×2轨迹，共约72单元，pilot只用于工程和成本。冻结组仍能读全部同例子。开发反馈最干净的方式是仅来自已揭示gold的适应样本。实例、决策数和内嵌guideline例子分别计量。

已采纳：测试隔离与冻结、监督账本、嵌套轨迹及文档聚类统计、预注册质量阈值、未达到阈值不外推、oracle诊断、强弱模型资产交换、减少pilot配置。正式轨迹数需依据pilot方差；三次/五次没有天然充分性。

## R3：benchmark 与数据

首轮与复核发现：

- SNACS/STREUSLE适合分离目标识别和语义标签，但与EWT reviews有文本重叠。
- UD LAS忽略依存关系子类型，必须另报full-label/现象指标。
- DISRPT orig_label直接泄漏gold；given spans仅支持关系分类结论。
- 当前GUM与DISRPT2023旧版本不能混用统计与标签表；底层文本许可不等于标注许可。
- MAVEN隐藏评测与任务格式带来额外成本，代码许可不能替代数据许可。
- 自然版本diff必须由专家区分规范迁移、纠错、文本/分词变化。

已采纳：主组合UMR+SNACS+GUM，UD专项；版本锁定、输入投影与跨语料分组；明确未完成的guideline/许可/评测器核验。完整审查见benchmark-audit.md。

## 整体判断

这一研究值得开展，但现阶段只是可执行的研究设计，不是已经成立的ACL贡献。负结果可以有价值，前提是能隔离机制、公开审计证据并排除成熟基线的解释。下一阶段应先完成最近邻审读和数据/评测审计，再运行pilot；不能挑选只让agent赢的任务。

## 终审修订

R2要求补充公开数据污染边界、预算0的log₂(1+B)定义和未见构式的材料曝光审计，均已采纳。R3要求将“没有现成benchmark”改为“本次核验候选中尚未确认”，已采纳。终审不代表最近邻全文核验或模型实验已完成。

新增Manifesto、Fashionpedia和跨领域审查。实际完成60次非LLM对照；代码评审发现并修复finish schema、标签合法性及截断usage记录问题。10项测试通过；两位reviewer独立核对60份预测与统计一致。后续另由主agent核验60次官方psseval一致，并在锁定依赖环境重现预测哈希。贡献reviewer明确判定现阶段不具备完整ACL实证投稿条件：没有agent运行、最近邻复现或跨域模型结果。
